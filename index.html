PAUMOVision Database Backup

These backups protect the searchable PAUMOVision records stored in Firestore. They do not contain the large MOV evidence files themselves. JSON preserves document IDs and Firestore timestamps for restoration; Excel is a human-readable archival copy.

Recommended zero-budget backup: use Save JSON to Synced Folder and choose a PAU OneDrive/SharePoint-synced folder on the office computer. PAUMOVision writes the backup file locally; OneDrive then synchronizes that backup to SharePoint. Browser permission is required each time.
Restore is intentionally non-destructive: it merges operational records by their original document IDs and does not erase newer records. User accounts, audit logs, and login activity are backed up but are not restored automatically.

Recommended PAU Workflow

1
Store the actual MOV file

Place the video, PDF, photo, or document inside the PAU SharePoint/OneDrive archive.

2
Record the MOV link in PAUMOVision

PAUMOVision keeps the searchable metadata and the secure external link instead of consuming database storage.

3
Back up the database regularly

Save a JSON backup to the synchronized PAU folder and keep another copy on an office computer or external drive.

Zero-budget storage policy

Firestore: lightweight records, metrics, metadata, links, and reports.
SharePoint / OneDrive / Drive: actual large MOV evidence files.
Cloudinary: remains supported for the current small PDF/photo modules.
Database protection: JSON + Excel backups, with JSON recommended for restoration. This build does not depend on Firebase Storage.
